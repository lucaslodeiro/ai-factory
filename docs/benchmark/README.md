# Benchmark baselines

Saved runs of the benchmark issue described in [../BENCHMARK.md](../BENCHMARK.md),
written by `factory benchmark <work-item-id> --save`. Keep one file per run, named
by date, so a later run can be compared against any earlier one.

These are measurements of the factory, not of the target application. A file
here is only comparable to another file produced from the same issue text.
