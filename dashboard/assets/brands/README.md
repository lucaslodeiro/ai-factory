# Brand assets

These files are bundled locally so the dashboard does not depend on a third-party CDN.

- `github.svg` comes from the [official GitHub logo package](https://brand.github.com/foundations/logo).
- `git.svg` comes from the [official Git logo page](https://git-scm.com/downloads/logos). The Git logo is by Jason Long and is licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
- `openai.svg`, `claude.svg`, and `slack.svg` use the corresponding marks distributed by [Simple Icons](https://simpleicons.org/) under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Product names and trademarks remain the property of their respective owners.

- `cursor.svg` is the Cursor mark from [Simple Icons](https://simpleicons.org/?q=cursor), distributed there under CC0-1.0.

The OpenAI mark represents the Codex provider in the UI. It intentionally appears without a visible text lockup; accessible labels still identify the control as Codex.
